# conve-ult Comprehensive Test Document

This is an automated demonstration of **conve-ult**, a universal file converter powered by *Java*, **Apache POI**, and **Apache PDFBox**.

## Key Features

- **Any Image to Any Format**: PNG, JPEG, WEBP, GIF, BMP, TIFF, PDF
- **Any Document to Any Format**: PDF, DOCX, DOC, ODT, HTML, Markdown, Plain Text
- **High Performance**: Native JVM execution with zero heavy office daemon overhead
- **Precise Formatting**: Support for bold, italic, code blocks, lists, and tables

## Sample Table Data

| Component | Technology | Version | Purpose |
| Apache POI | Java Library | 5.2.5 | Word (.docx/.doc) document processing |
| Apache PDFBox | Java Library | 3.0.1 | PDF rendering, layout, and extraction |
| TwelveMonkeys | ImageIO Plugin | 3.10.1 | WebP, TIFF, and advanced image formats |
| CLI Architecture | Java Standard | Java 25 | Fast, self-contained CLI tool |
